### 🎐 About Me
I'm a Product Designer and frontend/mobile engineer based in Alexandria, Egypt, and a recent graduate in Computer Science and Artificial Intelligence from Pharos University. I like owning the full pipeline of a product — research, wireframes, high-fidelity prototypes, then the actual React or Flutter build that ships to users.

**A few things I care about:**
- ☁️ **Data-Driven UI:** Grounding interface decisions in real user data, not assumptions.
- ☁️ **Inclusivity:** Accessible, WCAG-compliant experiences by default, not as an afterthought.
- ☁️ **Seamless Handoff:** Design-to-development handoffs that don't lose fidelity along the way.
